# paperclip-korean-ui

Paperclip 공식 dist를 고치지 않고 크롬 UI를 한국어로 덮는다.

- 기본 언어: 한국어
- 상단 `한 | EN` 토글, `localStorage paperclip.uiLanguage`
- 문구 정본: `locales/chrome.ko.json`, `locales/skills.ko.json`.

설정 화면(일반·실험·멤버·시크릿 등)은 `chrome.ko.json`의 `settings` 섹션이다. 짧은 단어(General, Access)는 설정 경로에서만 바꾼다.

결정 목록·복구 카드·조치 메뉴는 `decisions` 섹션이다. 시스템 문구만 화면에서 번역하고 이슈 본문·로그·오류 코드·담당자 이름·DB 원문은 바꾸지 않는다. 다른 화면의 일반 단어에는 이 번역을 적용하지 않는다.

## 1.1.14 변경 사항

- document.title은 알려진 페이지 이름만 번역하고, Paperclip 앞 회사명 칸과 원본 제목을 보존해 한/EN을 되돌린다.

## 1.1.13 변경 사항

- 사이드바 Status/beta와 계정 배지 Account, 결정/상태 문서 제목을 한국어로 표시한다.
- 상태 화면 빈 카드 안내를 한국어로 표시한다. Aoom/Paperclip 브랜드와 ID는 제목에 남긴다.

## 1.1.12 변경 사항

- 계정 메뉴의 테마 전환·서버 정보 고정 라벨을 한국어로 표시한다.
- 결정 화면의 Aging/지금 결정/실행 보기 등 고정 크롬과 런 세션 고정 문구를 한국어로 표시한다.
- Star/Unstar 접근성 라벨은 접두만 바꾸고 대상 이름은 그대로 둔다.

## 1.1.11 변경 사항

- 사이드바 플러그인 링크에 말줄임·title을 씌워 잘림을 줄인다. 공개 패키지에 회사 브랜드 문구를 넣지 않는다.
- 계정 메뉴 팝오버가 화면 위로 잘리지 않게 위치·최대 높이·스크롤을 보정한다.
- 실행 목록의 잘린 markdown 미리보기 기호는 한국어에서만 걷고, 한/EN 전환 시 원문을 복원한다.
- Tasks Touched·계정 메뉴 고정 라벨을 한국어로 표시한다. 공식 dist와 aoom-connect 공유 파일은 수정하지 않는다.

## 1.1.10 변경 사항

- 회사 설정의 배포 노출 라벨(인증된 공개)을 한국어로 표시한다.

## 1.1.9 변경 사항

- 에이전트 대시보드 상태 차트·라이브 배지·어댑터 설정 안내·도구 접근 안내 문장을 한국어로 표시한다.
- 스킬 이름, 모델 ID, 어댑터 브랜드는 그대로 둔다.

## 1.1.8 변경 사항

- 에이전트 탭 스킬·차트 라벨·회의실/위키 크롬을 한국어로 표시한다.
- 모델 ID와 어댑터 브랜드 이름은 그대로 둔다.

## 1.1.7 변경 사항

- 에이전트 상세 탭·설정·권한·도구·실행·예산 고정 메뉴를 한국어로 표시한다.
- 모델 ID, 에이전트 이름, 실행 상태값, 로그 본문은 그대로 둔다.

## 1.1.6 변경 사항

- 펼친 시스템 알림의 접힌 제목·메타 라벨(담당, 실행 근거 등)을 한국어로 표시한다.
- 이슈 상세 우측 속성 패널 고정 라벨(속성, 관계, 실행 등)을 한국어로 표시한다.
- 상태값·이슈 ID·사용자 본문은 그대로 둔다.

## 1.1.5 변경 사항

- 이슈 상세 시스템 알림(`task-chat-system-notice`)의 등록된 고정 문구를 한국어로 표시한다.
- 일반 이슈 본문 `.prose`와 코드·ID·상태값은 그대로 둔다.

## 1.1.4 변경 사항

- 결정 목록의 날짜·분류·메뉴와 자동 복구 사유를 한국어로 표시한다.
- 축약된 시스템 안내도 번역하며 한/EN 전환으로 원문을 복원한다.
- `npm test`로 번역·원문 복원·코드/본문 보존을 검사한다.

## 빌드·설치

```sh
git clone https://github.com/AoomORG/paperclip-korean-ui.git
cd paperclip-korean-ui
# Node >= 24.11
npm ci
npm run build
```

그다음 Paperclip에 로컬 경로로 설치한다. 로컬 경로는 개발용이다. 배포용 npm 패키지 공개는 아직 하지 않는다.

Node.js 24.11 이상이 필요하다. SDK는 현재 검증한 Paperclip과 같은 `2026.831.1`에 고정한다. 다른 버전의 호환성은 별도로 확인한다. 개인 npm 캐시나 회사 DB는 설치에 필요하지 않다.

패키지 파일은 `npm pack`으로 만든다. 빌드가 먼저 실행되며 dist·README·패키지 설정만 포함한다. 소스 레포에는 src·locales·빌드 스크립트·lockfile을 보관한다. npm 공개 배포는 아직 하지 않는다.

스킬 파일(`SKILL.md`)은 번역하지 않는다. 화면에 보이는 설명만 카탈로그가 있으면 한글로 바꾼다.
